## Cohort and source qualification

The twelve project-reserved CORD test images 012–023 were selected before source
inspection. This is a fresh project evaluation, not a guarantee that the model
publisher never used these public sources. The first native run returned two
readings, then rejected image 014: its 1,836 × 3,264 pixels exceed the unchanged
4,000,000-pixel research-panel boundary. A separately frozen continuation read
the other nine original PNGs once. No completed inference was repeated.
The initial plan retains inherited development descriptions; its explicit
selected IDs, twelve-case freeze and actual counters establish evaluation scope.
Those inherited descriptions are not evidence of zero evaluation exposure.

All twelve cases remain in cohort coverage and scoring: eleven returned
readings and one input failure. That failure is specific to this raw-input
research protocol. The application's existing image preparation can resize
uploads; this study did not run that browser preparation or establish that the
application rejects the original photo. No input was resized or substituted.

All outputs were hash-frozen before the twelve source images and raw upstream
annotations were inspected. Partial references contain 37 visible priced
components, including explicit zero-price subitems/packaging. Unit prices are
known for seven components, and final totals for eleven receipts. Unknown facts
remain unknown. Source review corrects two character transcriptions and keeps
an upstream-labelled subtotal separate from a grand total. A coupon printed
among payment rows remains tender. Percentage discounts are preserved without
inventing monetary deductions. Raw images and upstream labels are unchanged.
These are assistant source-reviewed references, without independent human or
complete-financial verification.

## Runtime, checks and decision

Eleven actual native OCR calls return. Their retained capture durations have
median 625 ms and mean 636 ms, including diagnostic serialization; these are
not full upload-to-review latency or evidence of a grouping speedup. Both native
controllers finish within the unchanged memory/time limits and their owned
processes close. The nine-case continuation's minimum sampled available memory
is 1,668,300,800 bytes. No persistent model/image installation or private provider
upload occurs. Public model wheels are checksum-verified in memory, and
networking is disabled before receipt access. OpenAI calls remain zero.

Native and browser geometry implementations produce identical words and lines
on all eleven returned SDK observations. The offline replay closes normally
with zero network attempts. Its initial `--jitless` attempt fails during Vite
import because that flag disables WebAssembly; the retained second attempt
uses normal Node execution with the same 384 MiB heap and no model rerun.

All 225 application/test source hashes still match the previously verified
1,381-case, 78-file checkpoint. No new software-suite run is claimed or required
for this evidence-only change. The current provider defaults and all protected
checkouts remain unchanged. The full twelve-phase goal remains incomplete.
